# Smart Cart Rover – Autonomous Retail Assistance System

> 🚀 An AI-powered autonomous retail assistant built using computer vision and robotics

## 📌 Overview
The Smart Cart Rover is an autonomous shopping assistant designed to enhance retail experiences using computer vision and robotics. The system is capable of detecting products in real-time and assisting users with navigation inside a store environment.

## 🚀 Features
- Real-time object detection using YOLOv8  
- Autonomous navigation concept (sensor-based / vision-based)  
- Robotic system design for product interaction (planned)  
- Modular architecture for scalability  

## 🛠️ Tech Stack
- Python  
- YOLOv8 (Ultralytics)  
- OpenCV  
- Raspberry Pi / Embedded Systems  
- SolidWorks (for 3D design)  

## 🧠 System Architecture
The system integrates computer vision with robotic mobility:
1. Camera captures real-time video input  
2. YOLOv8 model performs real-time product detection and classification  
3. Processing unit (Raspberry Pi) interprets data  
4. Navigation logic guides movement
